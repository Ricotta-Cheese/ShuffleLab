# Shuffle Lab

배열을 무작위로 섞는 **셔플 알고리즘 네 가지**를 직접 구현하고, 동작 과정을 시각화하고, **관계성 · 균등성 · 효율성**을 실험으로 비교하는 웹앱입니다.
2026학년도 2학기 알고리즘 과제(주제 A: 알고리즘 동작 시각화)를 위해 만들었습니다.

- 사이트: https://shuffle-lab-pi.vercel.app
- 보고서: [Report-Docs](Report-Docs) 폴더 (PDF · Word)

비교하는 알고리즘은 **Fisher–Yates**, **Random Pick & Remove**, **Riffle Shuffle(7회)**, **Random-Key Sort**입니다.

## 사이트 둘러보기

사이트는 위쪽 메뉴의 A부터 G까지 일곱 화면으로 되어 있습니다. 앞에서부터 차례로 보면 **알고리즘 이해 → 동작 확인 → 실험 → 종합 비교** 순서로 이어집니다.
화면마다 맨 위에 "이 화면에서 확인할 것"과 관련 연구 가설(H1~H4)이 있고, 맨 아래의 이전/다음 버튼으로 옆 화면으로 넘어갈 수 있습니다.

## 상단 바

### 메뉴 (A ~ G)

| 메뉴 | 하는 일 |
|---|---|
| **A 설명** | 프로젝트 소개, 주제를 고른 이유, 분석 관점, 연구 가설 H1~H4, 참고 문헌, 저장소·보고서 링크 |
| **B 알고리즘** | 네 알고리즘의 복잡도 비교표, 원리, 의사코드와 C++·Python·Java 코드, 시간·공간 복잡도와 균등성의 이유 |
| **C 동작 시각화** | 원소 2~10개로 셔플을 한 단계씩 재생해요. 단계마다 "무엇을, 왜" 했는지와 의사코드의 현재 줄, 연산 횟수를 함께 보여줘요. **전체 펼치기**로 바꾸면 모든 단계를 위아래로 펼쳐 한눈에 볼 수 있어요. |
| **D 관계성** | 한 번 섞은 결과가 원본 순서와 얼마나 닮았는지 Kendall's τ로 재고, 같은 입력을 2,000번 섞었을 때 τ의 분포를 보여줘요. |
| **E 균등성** | 같은 알고리즘을 최대 100만 번 돌려 순열별 확률을 재고, 균등분포와의 차이(TVD)를 이론값과 비교해요. |
| **F 효율성** | 배열 크기를 두 배씩 늘리며 실행 시간을 재요. 크기가 두 배일 때 시간이 몇 배가 되는지로 O(n)과 O(n²)의 차이를 확인해요. |
| **G 전체 비교** | D·E·F에서 잰 결과를 알고리즘별로 한 표에 모으고, 표준 조건으로 한 번에 다시 잴 수 있어요. |

E · F 화면에는 보고서와 같은 조건으로 바로 실험할 수 있는 **추천 실험 · 추천 설정** 버튼이 있습니다.

### 오른쪽 버튼

| 버튼 | 하는 일 |
|---|---|
| **실험 가이드** (지도 아이콘) | 보고서의 흐름대로 실험을 따라가는 11단계 안내를 시작해요. 단계마다 필요한 화면과 조건을 대신 열고, 확인할 곳을 강조하고, 보고서 값과 지금 측정한 값을 나란히 보여줘요. 누를 때만 시작하고, ✕나 같은 버튼으로 언제든 끝낼 수 있어요. |
| **콘솔** (터미널 아이콘) | 연산 과정을 시간순으로 기록하는 콘솔 창을 열고 닫아요. 단계별 연산, τ 계산, 반복 실험 진행, 크기별 측정값이 여기에 쌓여요. |
| **테마** (해·달 아이콘) | 다크 모드와 라이트 모드를 바꿔요. 고른 테마는 브라우저에 기억돼요. |

버튼 위에 마우스를 올리면 이름표가 떠요.

## 알아 두면 좋은 점

- 같은 시드는 항상 같은 결과를 만들어요. C · D 화면의 알고리즘 · 원소 수 · 시드는 주소에 남아서 그대로 공유할 수 있어요. 예: `/visualize?algo=fisher-yates&n=6&seed=1`
- C 화면에서는 키보드 ← · → 로 단계를 넘기고, 스페이스로 재생 · 일시정지해요.
- E · F의 반복 실험과 측정은 별도 스레드(Web Worker)에서 돌아서 화면이 멈추지 않아요. 측정하는 동안에는 탭을 화면에 띄워 두세요.
- D · E · F에서 잰 결과는 브라우저에 저장되고, G 화면에서 모아 볼 수 있어요.
- 관계성 지수 R은 원본과 닮은 정도일 뿐 **무작위성 점수가 아니에요.** 균등한 셔플도 원본과 닮은 결과를 낼 수 있어요.
